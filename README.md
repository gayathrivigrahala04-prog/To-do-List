# To-Do List Application

This project is a simple console-based To-Do List application developed using Python. The application allows users to manage their daily tasks through a Command-Line Interface (CLI). Users can add new tasks, view existing tasks, and remove completed tasks.

The application stores tasks in a text file, which makes the data persistent. This means that tasks remain saved even after the program is closed and reopened.

## Features

* Add new tasks
* View all tasks
* Remove tasks
* Store tasks in a text file
* Persistent data storage
* Menu-driven CLI interface

## Technologies Used

* Python
* VS Code
* GitHub Desktop
* Text File Handling

## Project Structure

```text
todo.py
tasks.txt
README.md
```

## How to Run

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

```bash
python todo.py
```
